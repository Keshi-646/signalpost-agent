# Submission email checklist

Send to: submit@builderr.ai

Subject suggestion: `Signalpost Hackathon Submission — Signalpost Agent`

Include:
- GitHub repository URL
- Exact commit hash (`git rev-parse HEAD`)
- One run command: `python -m streamlit run app.py`
- Model details: no LLM used in the baseline
- API details: Brønnøysund Register Centre public entity API
- Expected paid API cost: $0 baseline, subject to current API terms; hosting/electricity excluded
- Actual number of unique profiles collected and how verified
- Test command and test results
- Any limitations you have not yet implemented

Do not claim 1,000 profiles until you have confirmed that the database contains at least 1,000 unique, real records. Attach or link the required code and files as specified in the competition rules. Also share the project link on Unstop before the deadline.
